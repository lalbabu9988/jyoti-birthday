# For Jyoti ❤️ — Birthday Surprise Website

A cinematic, romantic birthday website made for Jyoti.

## Files

- `index.html` — main website
- `style.css` — complete design and animations
- `script.js` — countdown, typing effect, gallery, hearts, music and surprise interactions
- `photos/img1.jpeg` ... `photos/img6.jpeg` — your six photo slots
- `music.mp3` — optional: add your own legally obtained song here

## Add your 6 photos

Put your six photos in the `photos` folder and name them exactly:

- img1.jpeg
- img2.jpeg
- img3.jpeg
- img4.jpeg
- img5.jpeg
- img6.jpeg

The gallery is already coded to show **3 photos per row on desktop**, with equal-size square cards. On phones it becomes 2 columns.

## Add background music

Put a song you have the right to use in the website's main folder and name it:

`music.mp3`

The visitor must click the Music button because modern browsers usually block audio autoplay.

## Preview on your computer

1. Unzip the folder.
2. Double-click `index.html`.
3. The website opens in your browser.
4. For the easiest GitHub Pages setup, upload the whole folder contents to a GitHub repository.

## GitHub

Suggested repository name:

`for-jyoti-birthday`

Suggested website title:

`For Jyoti ❤️ | A Little World Made For You`

GitHub Pages URL will normally look like:

`https://YOUR-USERNAME.github.io/for-jyoti-birthday/`

## Personalize

You can edit the text directly in `index.html` and the birthday letter in `script.js`.

The timeline currently uses general wording because exact first-meeting dates/details were not provided.
